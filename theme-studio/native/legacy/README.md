# 旧版 64×64 主题原生适配

53 款主题使用 ESP32-S3 的 C/C++ 机器码和 CWP3 包，适用于 Runtime API 4 及以上。世界地图参数需要 Runtime API 5。

运行 `python theme-studio/native/build.py` 会一并构建这些应用。它们作为独立应用安装到应用存储，固件内置应用列表保持原有六款。

迁移工具读取原有公开设计。简单绘图表达式在构建时转换成 C++，角色状态机、重力模拟、实时温湿度和日照地图采用独立 C++ 实现。原始图像和 CWA 动效素材保留，运行时采用固定容量解码缓存，逐帧绘制不分配内存。

- `ports/` 保存独立 C++ 实现。
- `themes/` 保存生成的每款 C++ 源码、资源及清单。
- `migrate.py` 可重新生成、编译并更新应用目录。
- `verify.py` 运行每款 800 帧的电脑检查，并与旧版解码器逐像素比较动画帧。
- `install.py --device http://设备IP` 上传到目标设备，逐项回读 SHA-256、运行状态和帧率，最后恢复原主题。

世界地图使用 NOAA 太阳位置近似公式，根据设备日期、时间和「时区 UTC 偏移」参数计算晨昏线。偏移默认 +8，与中国标准时间相对应。变更设备时区时应同步调整此参数。

Girl 和皮卡丘保持每秒一个动作节拍。马里奥原版保留分层卷动与时间变化顶方块。疯狂动物城保留独立随机眨眼和心跳。传感器缺失时显示离线状态。
