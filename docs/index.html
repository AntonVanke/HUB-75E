烧录前看这里

  1. 1
    核对 Flash 与 PSRAM

    S3 固件面向 8 MB Flash + OPI PSRAM 本板；S3 N4（4 MB）不能刷此包。

  2. 2
    选择开发板的 USB 串口

    使用支持 Web Serial 的桌面 Chrome / Edge。若串口被占用，请关闭串口监视器。

  3. 3
    安装后配置 Wi-Fi

    进入「设备配置」手动连接串口，或打开设备自己的网页后台。

保留设置更新仅写入应用和 OTA 启动选择，适用于本项目兼容分区。全新安装使用合并固件，会重置 Wi-Fi 与设置。整片擦除会清空已安装应用。

发现局域网时钟

由已连接 USB 的时钟在自己的 Wi-Fi 子网内发现本项目设备，再通过串口返回结果；此网页不会扫描局域网 HTTP 地址。需 v0.9.8 或更新固件。

尚未开始发现。设备需先连接局域网 Wi-Fi。

不同子网、访客隔离或阻止广播的网络可能无法发现设备；也可从串口状态获得 IP 后直接打开设备后台。

屏幕方向

读取 v0.9.8 或更新固件的状态后可设置方向。

关闭自动方向或传感器数据暂不可用时，使用手动角度。方向设置在设备保存，重启后保留。
