脚本 API / 动画资源 / 随机种子

start() 初始化；update(dt) 更新；draw() 绘制；second() / minute() 时间事件；button(key) 按键。坐标 0–63；颜色支持 RGB565 数字与 #RRGGBB。


media.draw(id,x,y,毫秒) 播放原版动画；font.draw("mario",x,y,内容,颜色,缩放) 绘制原版字体，另有 pixel / segment / thin / sans / bold / italic 和 menu12 中文字体；rng.int(a,b) / rng.float() / rng.seed(n) 可复现的随机数。




动画资源以 manifest 清单为准；自定义脚本可自由组合资源、图层和图形。静态背景缓存到 layer；不要在 draw 中创建表格、拼接资源或逐像素循环。
nav.bfs(w,h,map,start) 返回网格距离；nav.solve(w,h,map,start,costs) 返回距离、首步、父节点三张表。网格最多 256 格，以 # 表示墙，索引从 1 开始。
